# C06: QA de paciente em IMRT/VMAT

A ficha de fonte **TG-218** traz o detalhe. Aqui fica o resumo operacional.

| Item | Regra | Fonte |
| --- | --- | --- |
| Método | True composite; PFF se o dispositivo não servir; **nunca perpendicular composite** | TG-218 [p. 26] |
| Análise | Dose absoluta, normalização **global**, limiar 10% | TG-218 [p. 26] |
| **Tolerância / ação** | Gama **3%/2 mm ≥ 95% / ≥ 90%** | TG-218 [p. 26] |
| Câmara + filme | Câmara: 2% / 3% | TG-218 [p. 26–27] |
| SRS/SBRT | Critérios mais apertados | TG-218 [p. 26]; MPPG-9a |
| Limites locais | Controle estatístico: ação ΔA = β√(σ² + (x̄−T)²), β = 6; tolerância = x̄ − 2,66 m̄R | TG-218 [p. 24] |
| Dispositivo | **Obrigatório** para IMRT: dispositivo planar (resolução ≥ 1 cm) e câmara < 0,1 cm³ | NN-6.10 art. 51, I [p. 12–13] |
