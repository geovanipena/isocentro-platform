# Adendo ao TG-51 (AAPM, 2014): dosimetria de referência de fótons de alta energia

**Em uma frase.** Mantém o formalismo do TG-51, mas traz **novos kQ por Monte Carlo** para as câmaras atuais, **especifica a "câmara de classe de referência"** (fuga, polaridade, recombinação, estabilidade), orienta **feixes FFF** e mostra **orçamentos de incerteza** da dose de referência.

O PDF tem cerca de 25 páginas; texto limpo ("<" preservado na Tabela III).

## Câmara de classe de referência (Tabela III) [TG-51-ADD-2014 p. 15–16]

| Grandeza | Especificação |
| --- | --- |
| Assentamento | < 0,5% de mudança na leitura/UM do feixe ligado até estabilizar |
| P_leak | < 0,1% (0,999 < P_leak < 1,001) |
| P_pol | < 0,4% (0,996 < P_pol < 1,004); variação com a energia < 0,5% |
| P_ion | Linear com a dose por pulso; recombinação inicial < 0,2%; diferença entre polaridades < 0,1% |
| Estabilidade | < 0,3% no coeficiente de calibração em **2 anos** |

## Recomendações de implementação (seção 4) [TG-51-ADD-2014 p. 5–8]

- Usar os **kQ da Tabela I** (Monte Carlo, válidos para 63 < %dd(10)X < 86); ex.: **PTW 30013** kQ = 0,996 / 0,991 / 0,982 / 0,975 / 0,967 em %dd(10)X = 63 / 67 / 73 / 77 / 81; IBA FC65-G 0,997 / 0,992 / 0,983 / 0,976 / 0,968 [p. 5].
- Só **câmaras cilíndricas** para fótons; câmaras < 0,05 cm³ **não** para referência.
- **Verificar o desempenho da câmara em toda calibração anual** e a cada feixe novo (não basta medir no comissionamento).
- Tensão de polarização: a do certificado; **no máximo 300 V**.
- **P_pol** medido em cada combinação câmara–feixe nova e **pelo menos anualmente**.
- Ponto efetivo: 0,6 r_cav só para medir PDD (efeito no kQ < 0,1%).
- Folha de chumbo para %dd(10)X dispensável em feixes com filtro ≥ 10 MV (Eq. 15 do TG-51, erro ≤ 0,2% no kQ); **obrigatória em FFF**.
- **Fantoma de água obrigatório** (proíbe plástico para calibração).
- **FFF**: TG-51 se aplica; **P_ion ≤ 1,05**; câmara de volume coletor curto ou correção de não uniformidade radial; câmaras com eletrodo de alto Z podem errar > 1% no kQ.

## Como se aplica no CLINICA

- A03/A15: as clínicas calibram pelo **TRS-398**; usar este adendo para conferir a **câmara de referência** (PTW 30013 na CEL, FC65 nas outras, conforme o PPR) pelos critérios da Tabela III na calibração anual e para os feixes **FFF do TrueBeam** (6FFF e 10FFF): P_ion, folha de chumbo e correção de volume.
- A04/A05: registrar P_pol e P_leak anuais da câmara; variação acima dos limites é sinal de câmara a revisar.
- Achado já registrado na base: o pylinac usa kQ do TRS-398 de 2000 (ver ficha do pylinac).
