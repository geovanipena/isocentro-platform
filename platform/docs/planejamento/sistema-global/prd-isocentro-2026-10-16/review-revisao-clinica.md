# Revisão de segurança clínica: PRD ISOCENTRO

Revisão adversária feita com o prompt `docs/qms/revisao-clinica.md`, aplicado
a `prd.md`. Os arquivos `escopo.md`, `classificacao-62304.md` e `riscos.md`
foram lidos como fato. O PRD não foi reescrito. As regras são as 1 a 9 do
prompt.
