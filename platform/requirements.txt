# ISOCENTRO — dependências fixadas.

# As versões são exatas de propósito: este app produz um documento clínico, e
# uma atualização silenciosa de dependência (pydicom lendo um header de outro
# jeito, matplotlib mudando um render) não pode entrar sem alguém decidir e
# reconferir. Para atualizar: suba a versão aqui, instale, rode
# tools/gerar_constraints.py e commite este arquivo junto com o constraints.txt
# (que fixa as dependências das dependências); depois revalide a ficha contra
# o TPS. Instalar sempre com: pip install -r requirements.txt -c constraints.txt
#
# Validado com Python 3.12 no Windows 11.

# regra de decisão manda a opção conservadora (AR-30). Só o Essentials: o
# metapacote PySide6 puxa o Addons (WebEngine, 3D, Charts...), que o app não
# usa e que seria SOUP a mais no inventário (R-83). Importa-se igual, PySide6.*.
